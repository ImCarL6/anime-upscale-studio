# Anime Upscale Studio 2.0.2

- Inclui um instalador leve que sempre busca a última release estável, confere a integridade do download e instala o pacote atual. Exige internet; o Setup completo continua disponível para uso offline da versão específica.
- Libera o espaço dos blocos recuperáveis e dos temporários após validar e salvar o vídeo final.
- Preserva originais, caches de outros trabalhos e os blocos de episódios com falha ou cancelados.
- Guarda as pequenas medições por bloco junto ao log, fora do cache de vídeo removido.
- Mantém a preparação paralela do próximo bloco no modo Máximo e as melhorias da interface V2.
