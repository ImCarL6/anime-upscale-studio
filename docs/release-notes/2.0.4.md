# Anime Upscale Studio 2.0.4

- Refina automaticamente as estimativas de tamanho e tempo dos próximos episódios a cada conclusão, dando peso crescente às medições reais e priorizando execuções recentes em condições semelhantes.
- Atualiza o tempo exibido em cada linha da fila e usa os tamanhos reais dos episódios concluídos no total previsto.
- Preserva a previsão original de cada episódio concluído para comparar com o resultado, inclusive depois de fechar e reabrir a fila.

[Baixar o instalador da última versão](https://github.com/ImCarL6/anime-upscale-studio/releases/latest/download/AnimeUpscaleStudio-Instalar.exe). O instalador leve consulta a versão estável atual a cada execução. O Setup completo desta release instala especificamente a 2.0.4.

Validação: compilação sem avisos, testes automáticos de aprendizado progressivo e compatibilidade do histórico, atualização das estimativas na interface e persistência entre sessões. Pacote e feed do atualizador conferidos sem instalar localmente. A precisão em episódios reais depende do conteúdo e das condições de uso do computador; esta versão não foi instalada localmente para preservar o teste do usuário pelo instalador.
