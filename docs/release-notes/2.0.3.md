# Anime Upscale Studio 2.0.3

- Instalador leve que consulta e instala a última release estável, mesmo quando o arquivo foi baixado numa versão anterior.
- Download com retomada pelo último byte salvo, limite de espera e novas tentativas automáticas em interrupções. Tamanho e SHA-256 são conferidos antes de instalar.
- Pede para fechar o aplicativo antes de instalar e permite cancelar o download. Exige internet; o Setup completo da versão continua disponível para uso offline.
- Inclui a interface V2, preparação paralela do próximo bloco no modo Máximo, pausa da fila por disco cheio e limpeza dos blocos somente após validar e salvar o vídeo final.

[Baixar o instalador da última versão](https://github.com/ImCarL6/anime-upscale-studio/releases/latest/download/AnimeUpscaleStudio-Instalar.exe). Você pode guardar esse arquivo: ele consulta a versão atual toda vez que é aberto.

Para instalar especificamente a 2.0.3 sem internet no computador de destino, use o `ImCarL6.AnimeUpscaleStudio-win-Setup.exe` completo desta release.

Validação: compilação e testes automáticos no Windows, seleção de versões futuras, integridade/cancelamento/retomada do download e download real completo de aproximadamente 936 MB com SHA-256 conferido, sem instalar durante esse teste. As validações do pipeline com GPU e da instalação local realizadas na 2.0.2 continuam descritas na documentação; não representam testes em Windows limpo ou num episódio inteiro nesta versão.
